Project Overview

NeoLung AI is an AI-assisted neonatal respiratory distress syndrome (RDS) triage system developed as a B.Tech final year project at Shri Guru Ram Rai University (SRHU), Dehradun. It uses a two-phase approach: a fast binary screen (Phase 1) followed by a 3-class severity assessment combining lung ultrasound (LUS) images and clinical vitals (Phase 2).

The system is built entirely on publicly available adult LUS data (covid19_ultrasound dataset) plus synthetically generated neonatal-domain images and clinical records derived from published RDS cohort statistics. No real neonatal patient data was used at any stage.

Methodology

Phase 1 — Binary CNN

  • MobileNetV3-Small backbone (~1.5 M params)
  • SSIM deduplication (threshold 0.98) on frame extraction
  • 6 neonatal domain-adaptation transforms
  • Stratified patient-level 70/15/15 split
  • WeightedRandomSampler + weighted CE loss

Phase 2 — Late Fusion

  • ImageEncoder: MobileNetV3 features → 576-d
  • ClinicalEncoder: 8 → 64 → 32-d MLP
  • FusionHead: concat(608) → 128 → 3 classes
  • Freeze encoder 5 epochs, then unfreeze all
  • 500 synthetic neonatal clinical patients
